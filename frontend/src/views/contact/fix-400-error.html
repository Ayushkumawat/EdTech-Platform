🚨 Fix Google Form 400 Error

Current Error:

Failed to load resource: the server responded with a status of 400

This happens because your form is using placeholder entry IDs instead of the actual Google Form entry IDs.

⚠️ Important

Your Google Form URL is: https://docs.google.com/forms/d/1SZAxMP0wi8Pe1P0mp4dlUHEzowGjNl3l_gQO0MYTzSI

You need to find the correct entry IDs for your 5 fields: Name, Email, Phone, Subject, Message

Step 1: Open Your Google Form Preview

  1. Go to: Open Form Editor
  2. Click the "Preview" button (👁️ eye icon)
  3. This will open the live form in a new tab

Step 2: Method 1 - Using Browser Console (Recommended)

  1. On the form preview page, press F12 to open Developer Tools
  2. Click on the "Console" tab
  3. Copy and paste this script:
document.querySelectorAll('input[name*="entry."], textarea[name*="entry."]').forEach((input, index) => { const entryId = input.name; const label = input.getAttribute('aria-label') || input.getAttribute('data-initial-value') || 'Unknown field'; console.log(`${index + 1}. ${entryId} - ${label}`); });

Press Enter to run the script. It will show you all the entry IDs!

Step 3: Method 2 - Using Network Tab (Alternative)

  1. On the form preview page, press F12 → Network tab
  2. Fill out the form with test data
  3. Click Submit
  4. Look for a request to formResponse
  5. Click on it and check the Request Payload
  6. You'll see the entry IDs with your test data

Step 4: Update Your Contact.tsx File

Replace the placeholder entry IDs in your code with the actual ones you found:

// Replace these placeholder IDs: googleFormData.append('entry.1234567890', formData.name); // Name field googleFormData.append('entry.1234567891', formData.email); // Email field googleFormData.append('entry.1234567892', formData.phone); // Phone field googleFormData.append('entry.1234567893', formData.subject); // Subject field googleFormData.append('entry.1234567894', formData.message); // Message field // With the actual entry IDs you found: googleFormData.append('entry.ACTUAL_ID_1', formData.name); // Name field googleFormData.append('entry.ACTUAL_ID_2', formData.email); // Email field googleFormData.append('entry.ACTUAL_ID_3', formData.phone); // Phone field googleFormData.append('entry.ACTUAL_ID_4', formData.subject); // Subject field googleFormData.append('entry.ACTUAL_ID_5', formData.message); // Message field

✅ After Updating the Entry IDs

  1. Save your Contact.tsx file
  2. Test the form by submitting it
  3. Check your Google Sheet to see if the data appears
  4. The 400 error should be resolved!

Step 5: Common Entry ID Examples

Entry IDs usually look like this:

entry.123456789 entry.987654321 entry.555666777 entry.111222333 entry.999888777

Each field in your form has a unique entry ID number.

Once you update the entry IDs, you can quickly test if they're working:

  1. Fill out your contact form
  2. Submit it
  3. Check if the success message appears
  4. Go to your Google Sheet to verify the data was saved
